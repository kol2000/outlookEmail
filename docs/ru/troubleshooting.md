# 🛠️ Устранение неполадок и часто задаваемые вопросы

## Устранение неполадок

### Контейнер не может быть запущен.

** Этапы проверки: **

```bash
# 1. Просмотр статуса контейнера
docker ps -a

# 2. Просмотр журналов приложений
docker logs outlook-mail-reader

# 3. Проверьте занятость порта.
lsof -i :5000

# 4. Снова вытащите образ и перезагрузите компьютер.
docker pull ghcr.io/assast/outlookemail:latest
docker-compose down
docker-compose up -d
```

** В правильном журнале должно быть указано: **.
```
============================================================
Веб-приложение Outlook Mail инициализировано.
Файл базы данных: data/outlook_accounts.db.
GPTMail API: https://mail.chatgpt.org.uk
============================================================
```

### Ошибка «Таблица базы данных не существует».

Сообщение об ошибке **: ** `sqlite3.OperationalError: no such table: settings`

** Причина: база данных ** не инициализирована или повреждена.

** Решение: **

```bash
# Способ 1. Удалите старую базу данных и повторно инициализируйте ее.
docker-compose down
rm -rf data/outlook_accounts.db
docker-compose up -d

# Способ 2: инициализация базы данных вручную.
docker exec outlook-mail-reader python -c "from web_outlook_app import init_db; init_db()"
docker-compose restart

# Способ 3. Используйте последнее изображение.
docker pull ghcr.io/assast/outlookemail:latest
docker-compose down
docker-compose up -d
```

### Невозможно получить почту

** Возможные причины: **
1. Срок действия токена обновления истек или недействителен.
2. Ошибка идентификатора клиента
3. Недостаточно разрешений API.
4. Проблемы с сетевым подключением

** Решение: **

1. ** Обновить токен** — обновить с помощью встроенного помощника OAuth2.
2. **Проверьте разрешения API** — убедитесь, что необходимые разрешения API добавлены.
3. **Просмотреть подробную информацию об ошибке **. Откройте инструменты разработчика браузера (F12) и просмотрите тег «Сеть».

### Ошибка 502 (Nginx)

** Причина: приложение ** не запустилось нормально или неправильная конфигурация порта.

```bash
docker ps
docker-compose logs
curl http://localhost:5000/login
sudo nginx -t
docker-compose restart
sudo systemctl reload nginx
```

### Функция временного почтового ящика недоступна.

1. ** Обновить ключ API ** — обновить ключ API GPTMail в «⚙️ Настройках»
2. ** Проверьте статус службы. ** — посетите официальный сайт GPTMail, чтобы подтвердить статус службы.

### Проблема с истечением срока действия сеанса.

1. Исправлена настройка SECRET_KEY** при развертывании сервера **.
   ```yaml
   environment:
     - SECRET_KEY=your-fixed-secret-key-here
   ```
   Создано с помощью `python -c 'import secrets; print(secrets.token_hex(32))'`.

   Если вы используете Windows `exe`, программа автоматически сгенерирует и сохранит фиксированный `SECRET_KEY` при первом запуске. Не удаляйте файл ключа в соответствующем каталоге данных.

2. Срок действия веб-входа по умолчанию составляет 30 дней. Вы также можете выбрать 7 дней, 90 дней, 180 дней или постоянный срок действия на странице входа; перезапуск приложения не приведет к тому, что сеанс станет недействительным (используйте фиксированный SECRET_KEY)

### Ошибка блокировки базы данных.

Сообщение об ошибке **: ** `sqlite3.OperationalError: database is locked`

```bash
docker-compose restart
lsof data/outlook_accounts.db
cp data/outlook_accounts.db data/outlook_accounts.db.backup
docker-compose down
docker-compose up -d
```

## Часто задаваемые вопросы

### Вопрос: Почему я не могу получить электронное письмо?
A: Проверьте: (1) действителен ли токен обновления (2) правильный ли идентификатор клиента (3) разрешения API приложения Azure (4) сетевое подключение (5) попробуйте получить токен еще раз

### Вопрос: Как получить токен обновления?
A: Используйте встроенный помощник OAuth2: нажмите «Получить токен» → «Создать ссылку для авторизации» → «Авторизация в браузере» → Скопируйте авторизованный URL-адрес → Вставить для обмена на токен.

### Вопрос: Как использовать функцию временного почтового ящика?
A: Нажмите группу «Временный почтовый ящик» → «Создать временный почтовый ящик» → выберите почтовый ящик → «Получить почту».

### В: Как изменить пароль для входа?
A: ** по-прежнему запоминает текущий пароль как **, который можно изменить в веб-интерфейсе «⚙️ Настройки» (необходимо ввести текущий пароль). Переменная среды `LOGIN_PASSWORD` ** записывается в значение по умолчанию только при первой инициализации ** (в базе данных еще нет `login_password`); после запуска приложения и написания библиотеки, только изменение env ** не приведет к перезаписи текущего пароля входа в систему на **.

### В: Что мне делать, если я забуду свой пароль для входа в Интернет?
A: Используйте официальный скрипт сброса (** не требует старого пароля **, но требует прав хоста для доступа к базе данных/контейнеру):

```bash
# Рекомендуется сначала остановить службу (не обязательно) и подтвердить DATABASE_PATH (данные по умолчанию/outlook_accounts.db).
python scripts/reset_login_password.py

# Пример Docker (имя контейнера изменяется в соответствии с реальной ситуацией; - его необходимо использовать для входа в интерактивный терминал)
docker exec -it outlook-mail-reader python scripts/reset_login_password.py
# Если имя службы создания — Outlook-mail:
# docker exec -it outlook-mail python scripts/reset_login_password.py
```

Введите и подтвердите новый пароль (не менее 8 цифр) при появлении соответствующего запроса. После успеха:

- Войдите с новым паролем ** **; существующие веб-/расширенные сеансы станут недействительными.
- Пароль сохраняется в базе данных `settings.login_password` (bcrypt), ** не является ** и может быть восстановлен путем изменения переменной среды `LOGIN_PASSWORD`.
- Сценарий не поддерживает `--password` или передаваемые по конвейеру пароли, поэтому его необходимо запускать в интерактивном телетайпе.

Более полное описание границ безопасности см. в [security.md](security.md).

### Вопрос: Где хранятся данные?
A: База данных SQLite `data/outlook_accounts.db`, рекомендуется регулярное резервное копирование.

### Вопрос: Какие почтовые папки поддерживаются?
A: Входящие, нежелательная почта, удаленные элементы.

### Вопрос: Как импортировать почтовые ящики партиями?
A: Формат по умолчанию: `Электронная почта ---- Пароль ----client_id ----refresh_token`, по одному в строке; он также поддерживает переключение на `Электронная почта ---- Пароль ----refresh_token ---- client_id` во всплывающем окне импорта.

### Вопрос: Как экспортировать учетную запись электронной почты?
A: (1) Экспорт одной группы (2) Экспорт всех (3) Экспорт выбранных групп (4) Экспорт выбранных учетных записей после пакетного выбора в списке почтовых ящиков.

### Вопрос: Как перетащить выбор пакета? Что делать, если трекпад моего Mac не отвечает?
A: Сначала нажмите «☑» в верхней части панели почтового ящика, чтобы войти в режим пакетного выбора, затем нажмите и перетащите вверх и вниз строку учетной записи или левое поле выбора. Просто удерживайте `Shift` и щелкните для непрерывного выбора диапазона, что не эквивалентно перетаскиванию; если вы хотите перетаскивать трекпад, вам нужно продолжать нажимать, чтобы просмотреть несколько строк учетных записей.

### Вопрос: Что делать, если Docker-контейнер не запускается?
A: (1) `docker logs outlook-mail-reader` (2) Проверьте порт (3) Проверьте права доступа к каталогу (4) Загрузите последний образ
