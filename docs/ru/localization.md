# Английская и русская локализация

Форк начинается с версии v3.0.9 (`d7a00986deb2e55f286e28b74e528c880cf98f42`). Панель инструментов приложения, страница входа, страница общей почты и расширение имеют селектор английского/русского языка. При смене языка страница перезагружается; сначала сохраните незавершенные изменения формы.

## Поведение во время выполнения

- Jinja переводит статические метки перед рендерингом с обычным экранированием HTML.
- JavaScript использует шаблоны с тегами `I18n.t(source)` и `I18n.tpl`. Значения шаблона вставляются после перевода и сохраняют исходное содержимое и исходное экранирование.
- Flask преобразует известные поля состояния приложения на границе ответа JSON/SSE. Значения базы данных, тела писем, темы, имена учетных записей, учетные данные, форматы импорта/экспорта и бизнес-решения не переводятся.
- Каталоги прилагаются к приложению. Никакой зависимости от сети перевода не добавляется.
- Явный заголовок `X-Outlook-Language` имеет приоритет над языковым файлом cookie, за ним следует язык браузера и `OUTLOOK_LANGUAGE` (по умолчанию `en`). Исходные сообщения API `zh-CN` остаются доступными для совместимости без дополнительной опции пользовательского интерфейса.
- Расширение сохраняет свои собственные языковые предпочтения и отправляет языковой заголовок на сервер.
- Панель рабочего стола/текст запуска следует за `OUTLOOK_LANGUAGE`; выбор браузера осуществляется для каждого браузера.

## Редактирование переводов

Отредактируйте `static/locales/en.json` и `static/locales/ru.json`. Исходный текст на китайском языке является стабильным ключом сообщения. Точно сохраните каждый заполнитель в стиле `{__0__}`; не переводите атрибуты HTML, такие как `class`, `id`, обработчики событий, URL-адреса или идентификаторы API. Экранировать переведенный текст внутри атрибутов шаблона HTML. Затем запустите:

```sh
python scripts/sync_locales.py
python -m pytest tests/test_i18n.py -q
node tests/i18n.test.cjs
```

Унаследованный пакет регрессии ожидает исходные сообщения китайского API, поэтому запустите его с помощью `OUTLOOK_LANGUAGE=zh-CN`. Тесты локализации явно запрашивают английский и русский языки. Несколько внешних тестов были обновлены для подтверждения новых вызовов перевода. Тест на ограничение количества страниц имитирует постоянство, поэтому он проверяет все 100 страниц без записи 10 000 строк; отдельные тесты охватывают настойчивость.

При проверке в песочнице Windows используются временные тестовые каталоги с унаследованными списками управления доступом рабочей области, поскольку список ACL для частных временных каталогов Python исключает токен ограниченного исполнителя. Это обходное решение с использованием тестового оборудования находится за пределами приложения и не требуется при обычной проверке.

## Объем и статус рассмотрения

Каталоги, метаданные расширений, README, инструкции по выпуску/сборке и текущие руководства пользователя/API имеют английскую и русскую версии. Первоначальный полный перевод был создан машиной; Общие метки интерфейса были отредактированы, а заполнители/разметка проверены. Длинные описания, возможно, все еще нуждаются в редакционной доработке. Исходные снимки экрана, исторические записи журнала изменений, комментарии к исходному коду и текст ошибок внешнего поставщика сохраняют исходный язык. Восходящий китайский файл README сохраняется как `README.zh-CN.md`.

Используйте локальную сборку этого форка. Вышестоящие исполняемые файлы и образы контейнеров не включают переводы. Ссылки на репозиторий и владелец проверки обновлений по умолчанию указывают на `kol2000/outlookEmail`; `REPOSITORY_OWNER` остается настраиваемым.

## Исходники и история

Комментарии, текущая документация и сообщения коммитов переведены на английский. История переписана с сохранением авторов, дат, связей и содержимого старых снимков; SHA коммитов изменились. Ключи новых переводов — английские строки. Старые идентификаторы базы и папок провайдеров сохранены через Unicode-коды ради совместимости. Режим `zh-CN` теперь возвращает исходные сообщения без перевода; новые сообщения сервера написаны по-английски.
