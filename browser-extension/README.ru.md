# Инструкции по расширению браузера OutlookEmail

Это расширение браузера Chrome/Edge для OutlookEmail. Расширение использует пароль для входа на веб-сторону для установления обычного веб-сеанса и не использует внешний ключ API; все запросы управления по-прежнему проходят через существующую защиту сервера Session + CSRF.

Расширение по умолчанию запускается на боковой панели браузера и не переключает текущую вкладку веб-страницы.

## Применимые браузеры

- Google Chrome, рекомендуется использовать более новую стабильную версию.
- Microsoft Edge, рекомендуется использовать более новую стабильную версию.
- Требуется поддержка браузером Manifest V3 и боковой панели.

## Установить расширение

1. Откройте страницу управления расширениями браузера:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. Включите «Режим разработчика».
3. Нажмите «Загрузить разархивированное расширение».
4. Выберите каталог `browser-extension` на этом складе.
5. После завершения установки на панели инструментов появится запись расширения `OutlookEmail`.

## Обновление расширения

После обновления кода необходимо вручную перезагрузить его на странице управления расширением:

1. Откройте `chrome://extensions/` или `edge://extensions/`.
2. Найден `Консоль OutlookEmail`.
3. Нажмите кнопку «Перезагрузить».
4. Снова откройте боковую панель.

Если на боковой панели по-прежнему отображается старый интерфейс, вы можете закрыть боковую панель и снова щелкнуть значок расширения.

## Первая настройка

1. Нажмите значок расширения OutlookEmail на панели инструментов браузера, чтобы открыть боковую панель.
2. Заполните «Адрес сервиса», например:
   - Локальное управление: `http://127.0.0.1:5000`
   - Развертывание сервера: `https://your-domain.example`.
3. Введите «Пароль для входа в Интернет», который используется для входа на веб-страницу OutlookEmail.
4. При необходимости установите флажок «Запомнить пароль к локальному браузеру».
5. Нажмите «Сохранить конфигурацию» или непосредственно нажмите на вход в функцию выше, чтобы начать ее использовать.

Описание:

- Если установлен флажок «Запомнить пароль для локального браузера», пароль будет сохранен в локальном хранилище расширений текущего браузера.
- Если флажок не установлен, пароль сохраняется только в хранилище уровня сеанса браузера; его необходимо ввести повторно после завершения сеанса браузера.
- Когда расширение впервые обращается к адресу службы, в браузере может появиться подтверждение разрешения доступа к сайту, для которого требуется разрешение.

## Ежедневное использование

После открытия боковой панели вы можете напрямую щелкнуть верхний вход в функцию:

- `Почтовый ящик`
- `Импорт`
- `Обновить`
- `Token`
- `Экспорт`
- `этикетка`
- `Настройки`

Кнопка шестеренки в правом верхнем углу боковой панели позволяет развернуть или свернуть область конфигурации. Кнопка `Обновить` перезагрузит текущую страницу функций.

## Электронная почта

Страница почтового ящика используется для просмотра и управления обычными почтовыми ящиками, временными почтовыми ящиками и всей почтой Cloudflare.

Основные способности:

- Выберите группу почтовых ящиков, и расширение запомнит последнюю выбранную группу.
- Поиск в обычных почтовых ящиках, поддерживающих почтовые ящики, заметки, метки или псевдонимы.
- Обычные списки почтовых ящиков поддерживают пейджинг.
- Нажмите «Почта» в строке учетной записи, чтобы напрямую просмотреть список рассылки.
- Список рассылки отображается над списком аккаунтов, поэтому нет необходимости долго прокручивать вниз среди большого количества аккаунтов.
- Сведения об электронной почте поддерживают просмотр текста, ввод вложений, пометку как прочитанные и удаление обычных электронных писем.
- Другие операции для обычных учетных записей включены в «Дополнительные операции»: редактирование, пометка, включение/выключение переадресации, обновление токена, копирование, удаление.

Временный адрес электронной почты:

- После входа в группу «Временный почтовый ящик» будет загружен список временных почтовых ящиков `/api/temp-emails`.
- Поддержка временных почтовых ящиков GPTMail, DuckMail, Cloudflare.
- Можно просмотреть одно сообщение временного почтового ящика.
- Временные почтовые ящики можно обновлять, копировать и удалять.
- Если настроена служба временных почтовых ящиков Cloudflare, будет отображаться запись `Cloudflare Вся почта`, и все электронные письма в текущем Worker можно будет просматривать и фильтровать по адресу получателя.

## Импорт

Страница импорта поддерживает обычные почтовые ящики и временные почтовые ящики.

Обычная электронная почта:

- Поддержка Outlook/Hotmail.
- Поддерживает Gmail, QQ, 163, 126, Yahoo, Alibaba Mail и другие почтовые ящики IMAP.
- Поддержка пользовательского IMAP.
- Вы можете выбрать целевую группировку, формат импорта, унифицированные примечания, статус, включить ли пересылку и привязать метки при импорте.

Распространенные форматы:

```text
Электронная почта ---- Пароль ---- ClientID ---- RefreshToken
```

Пользовательский формат IMAP:

```text
Электронная почта ----пароль IMAP ----хост IMAP ----порт IMAP
```

Временный адрес электронной почты:

- `gptmail`: Один почтовый ящик на линию.
- `duckmail`: `Электронная почта ---- Пароль` на строку.
- `cloudflare`: `Электронная почта ---- JWT` на строку.

Создайте временный почтовый ящик:

- Поддержка GPTMail/DuckMail/Cloudflare.
- DuckMail требует имя домена, имя пользователя и пароль.
- Cloudflare может указать имя домена и имя пользователя; имя пользователя можно оставить пустым и сгенерировать случайным образом.

## Обновить

Страница обновления используется для управления обновлением токена обновления учетных записей Outlook.

Основные способности:

- Просмотр статистики обновления.
- Фильтр по статусу: «Все», «Успешно», «Сбой», «Никогда не обновляется».
- Найдите учетную запись, которую необходимо обновить.
- Обновление одного аккаунта.
- Повторная попытка для одной учетной записи.
- Полное обновление.
- Ошибка повторной попытки потоковой передачи.
- Быстро повторите неудачные попытки.
- Остановить полное обновление.
- Просмотрите журнал обновлений и список ошибок.

Полные обновления и повторные попытки потоковой передачи показывают прогресс через SSE.

## Token

Страница «Токен» используется для получения токена обновления Microsoft OAuth и может быть непосредственно сохранена как учетная запись.

Процесс использования:

1. Скопируйте ссылку авторизации.
2. Полное лицензирование Microsoft в вашем браузере.
3. Скопируйте полный URL-адрес обратного вызова после авторизации.
4. Вернитесь на боковую панель и введите адрес электронной почты, пароль учетной записи и целевую группу.
5. Вставьте полный URL-адрес обратного вызова.
6. Нажмите «Активировать и просмотреть».
7. Нажмите «Сохранить учетную запись» после подтверждения правильности.

При сохранении учетной записи интерфейс импорта учетной записи сервера будет вызываться в соответствии с форматом импорта Outlook.

## Экспорт

Страница экспорта поддерживает экспорт учетных записей после двухэтапной проверки.

Процесс использования:

1. Введите пароль для входа в Интернет в качестве пароля двухэтапной проверки.
2. Выберите экспорт всех или отметьте группу, а затем экспортируйте выбранную группу.
3. Экспортированный контент будет отображаться в текстовом поле.
4. Вы можете нажать «Копировать результаты», чтобы скопировать экспортированный контент.

При экспорте групп временных почтовых ящиков соответствующее содержимое временного почтового ящика будет включено в соответствии с логикой экспорта на стороне сервера.

## тег

Поддержка вкладок:

- Создайте теги.
- Удалить тег.
- Пакетное добавление или удаление тегов для обычных учетных записей.
- Пакетное добавление или удаление меток во временных почтовых ящиках.

При пакетной привязке необходимо указать идентификатор учетной записи или временный идентификатор электронной почты. Идентификатор можно увидеть в списке почтовых ящиков.

## Настройки

На странице настроек представлены общие веб-настройки:

- Основные настройки обновления.
- Cron и часовые пояса приложений.
- Временная конфигурация службы почтовых ящиков.
- Конфигурация DuckMail.
- Имя домена Cloudflare Worker, имя домена электронной почты и пароль управления.
- Канал пересылки.
- Конфигурация SMTP/Telegram/Enterprise WeChat.
- Конфигурация резервного копирования WebDAV.
- Просмотр и изменение внешнего ключа API.

Конфиденциальные конфигурации на странице настроек будут записаны непосредственно в интерфейс настроек сервера. При изменении конфиденциальных настроек, таких как резервное копирование WebDAV, вам необходимо ввести соответствующий пароль проверки.

## Механизм входа в систему

Расширенный процесс входа в систему выглядит следующим образом:

1. Расширенный вызов `POST /api/extension/login`.
2. Сервер проверяет пароль для входа в Интернет.
3. Сервер возвращает одноразовый `launch_url`, действительный в течение 60 секунд.
4. Расширенный доступ к `launch_url`, сервер записывает обычный веб-сеанс под своим собственным доменным именем.
5. Последующие запросы на расширение используют этот сеанс и получают токен CSRF через `GET /api/csrf-token`.

Если версия сервера слишком старая и не имеет `/api/extension/login`, расширение попытается вернуться к интерфейсу входа в систему с паролем `/login`.

## Часто задаваемые вопросы

### После нажатия на функцию всегда отображается, что вы входите в систему.

Проверьте:

- Правильный ли сервисный адрес? Не пишите больше путей. Например, вам следует заполнить `https://your-domain.example`, не заполняйте `https://your-domain.example/#settings`.
- Правильный ли пароль для входа в Интернет?
- Разрешает ли браузер расширению доступ к этому адресу службы.
- Можно ли нормально открыть сервер.
- Разверните обратный прокси-сервер для правильной пересылки файлов cookie.

### Подскажите, что нужно разрешить доступ к адресу сервиса

Это запрос разрешений сайта для расширения браузера. Разрешите расширению запрашивать вашу службу OutlookEmail.

### Группа временных почтовых ящиков показывает, что учетной записи еще нет.

Группа временных почтовых ящиков не читает обычную таблицу учетных записей, а читает `/api/temp-emails`. Если на веб-стороне есть временный почтовый ящик, но расширение не отображается, сначала нажмите «Обновить» в расширении, а затем подтвердите, что текущий адрес службы подключен к тому же экземпляру сервера.

### Все электронные письма Cloudflare не содержат контента.

Проверьте конфигурацию Cloudflare на странице настроек:

- Доменное имя Cloudflare Worker.
- Доменное имя электронной почты Cloudflare.
- Пароль управления Cloudflare.

После настройки войдите в группу «Временный почтовый ящик» на странице почтового ящика и нажмите `Cloudflare Вся почта`.

### Интерфейс не изменился после обновления расширения.

Вам необходимо нажать «Обновить» на странице управления расширениями браузера. Простое обновление страницы не приведет к обновлению загруженного кода расширения.

### Не хочу сохранять пароль

Снимите флажок «Запомнить пароль к локальному браузеру». Таким образом, пароль сохраняется только в хранилище уровня сеанса браузера, и его необходимо вводить повторно после закрытия сеанса браузера.

## Описание документа

- `manifest.json`: Манифест Chrome Manifest V3.
- `background.js`: открывается боковая панель при нажатии на значок расширения.
- `sidepanel.html` / `sidepanel.css` / `sidepanel.js`: консоль боковой панели.
- `popup.html` / `popup.css` / `popup.js`: Совместим с входом через всплывающее окно.
- `api-client.js`: инкапсуляция запросов входа в систему, сеанса, CSRF, JSON/Text/SSE.
- `storage.js`: локальная конфигурация и хранилище состояний интерфейса.
